Explanation of columns

You can click on the student ID to see the marking page for that student.

Mark sheets
This lists the number of completed sheets for the student.
The markers are counted separately, so if there should be two marksheets and two markers this will be four when completed.
Final completed
True if all items have non-zero marks, False otherwise.
If a student has been given 0 for a section this will not show as completed (as there's no way to know).
Comments
Some markers have indicated in the comments if a section was not submitted/attended so part of the comment has been included.
